# BTVN-LTMM(Week7)
Cài đặt giải thuật thuật toán nhân 2 đa thức trong trường hữu hạn GF(2^4), GF(2^8) tương ứng với đa thức tối giản trong trường 

Hướng dẫn sử dụng:
Mở đầu chọn n = 4 hoặc n = 8 (Tương ứng với GF(2^4) và GF(2^8))
Với GF(2^4) có thể nhập 1 ký tự hex(0->F) cho cả a và b
Với GF(2^8) có thể nhập 2 ký tự hex(00->FF) cho cả a và b
Có thể nhập a và b theo 2 cách
VD: 57 hoặc 0x57
